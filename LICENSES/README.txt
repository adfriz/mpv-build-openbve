Third-party license texts are fetched at package time by scripts/package.sh
from pinned tags (mpv LICENSE.LGPL, ffmpeg COPYING.LGPLv2.1/v3, libass COPYING)
and bundled into each release archive under LICENSES/.

Canonical sources:
* https://github.com/mpv-player/mpv/blob/master/LICENSE.LGPL
* https://ffmpeg.org/legal.html
* https://github.com/libass/libass/blob/master/COPYING (ISC)

NOTE: this directory is for THIRD-PARTY license texts bundled into release
archives. This repo's own scripts/docs are MIT-licensed, see /LICENSE.
